# Diabetics_readmission_Dashboard
SQL and dashboard project on 100K diabetic hospital visits: which patients are readmitted within 30 days? 8 BigQuery queries plus an interactive HTML dashboard
## 📈 Interactive dashboard

I also built a dashboard to explore the results.

👉 **[Open the dashboard](https://claude.ai/artifact/5YMWMDwTAfHP4hUewNvdtj)** or download `diabetes_readmission_dashboard.html` and open it in your browser.

- 🔎 Filter by age group and gender
- 📊 Charts for age, earlier admissions, length of stay, insulin and discharge destination
- 🔢 Summary cards and a sortable table

Built with HTML, JavaScript and Chart.js. The numbers come from the same logic as the SQL queries.
